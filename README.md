HealthBot 🩺💬

HealthBot is a Flask-based AI health assistant with a modern chat interface powered by Groq and LangChain.  
It includes a responsive UI, chat history, a collapsible sidebar, a water tracker, and a step tracker.

 Features ✨

- AI chatbot using Groq + LangChain
- Modern responsive UI
- Sidebar navigation
- Chat history storage
- Water intake tracker
- Daily steps tracker
- Gradient navbar
- Real-time chat interaction
- Flask backend integration
- Proper user message formatting
